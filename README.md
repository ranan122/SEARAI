# SEAR AI website

The website for SEAR AI, published at https://searai.org with GitHub Pages.

SEAR AI offers developmental evaluation for child-facing AI. Contact: hello@searai.org

## Files

| File | What it is |
| --- | --- |
| `index.html` | Home page |
| `services.html` | Services and the sample scenario |
| `research.html` | Research and publications |
| `about.html` | About and commitments |
| `faqs.html` | Frequently asked questions |
| `contact.html` | Contact page |
| `404.html` | Shown when a page is not found |
| `styles.css` | Colors, fonts, and layout for every page |
| `site.js` | The copy button on the contact page |
| `CNAME` | Tells GitHub Pages the site's domain (searai.org) |
| `robots.txt`, `sitemap.xml` | Help search engines find the pages |

## Updating the site

The pages are plain HTML files. To change the site, replace the files here with the new versions and commit. GitHub Pages republishes within a few minutes.

All files must stay at the top level of the repository, next to this README.
